# Contributing

## Contributions written with AI

Agents are welcome here, under two rules:

- **An agent publishes nothing on its own initiative.** No pushed commit, issue, pull request or comment, unless the person it works for asked for that act, and that person answers for it.
- **Everything an agent writes for this repository says so.** A commit body, an issue, a pull request or a comment opens with a blockquote line starting `> 🤖 Written by AI`, completed with the contributor's own name.
